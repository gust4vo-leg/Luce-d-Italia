# Luce D'Italia 🇮🇹

## 🍝 Restaurante Italiano

Site institucional desenvolvido para o **Luce D'Italia**, um restaurante italiano inspirado na tradição, elegância e gastronomia da Itália.

O projeto foi desenvolvido com o objetivo de criar uma experiência digital sofisticada, combinando uma identidade visual clássica com uma interface moderna, intuitiva e responsiva.

---

## 📖 Sobre o Projeto

O site apresenta a identidade e a experiência do restaurante, permitindo que os visitantes conheçam sua história, explorem o cardápio, visualizem os pratos e encontrem facilmente as informações necessárias para entrar em contato ou realizar uma reserva.

A identidade visual foi construída a partir de uma estética italiana tradicional, utilizando elementos ornamentais, tipografia elegante e uma paleta de cores inspirada na cultura italiana.

---

## ✨ Funcionalidades

- 🏠 Página inicial

## 🎨 Identidade Visual

A identidade visual do **Luce D'Italia** foi desenvolvida para transmitir uma sensação de tradição, sofisticação e autenticidade italiana.

### Paleta de cores

| Cor | Aplicação |
| --- | --- |
| 🟢 Verde escuro | Elementos principais e fundos |
| 🔴 Vermelho vinho | Destaques e detalhes |
| 🤍 Creme | Fundos e áreas de conteúdo |
| 🟤 Marrom | Detalhes e elementos complementares |

A logo **Luce D'Italia — Dal 1879** funciona como elemento central da identidade do restaurante, reforçando a proposta de tradição e elegância do projeto.

---

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma presença digital que represente a essência do **Luce D'Italia**, unindo gastronomia, tradição e sofisticação em uma experiência web moderna e acessível.
